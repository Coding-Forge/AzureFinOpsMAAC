User Guide

Use the Azure FinOps MACC Retail Solution

This help page explains how to run the PowerShell UI, generate cost and retail comparison files, and use the Power BI report pages for MACC commitment tracking, savings validation, exceptions, and audit evidence.

PowerShell launcher Azure Cost Management Azure Retail Prices Power BI PBIP MACC audit ledger

Use the PowerShell launcher

1

Get the solution

Use the latest tagged release zip from the repository Releases page, or clone the repository if you are contributing changes. Extract the release zip to a local folder, then run the launcher from that extracted folder.

Start the launcher

Run the launcher from the solution folder:

powershell.exe -ExecutionPolicy Bypass -File .\scripts\Start-FinOpsDataPull.ps1
2

Choose the analysis purpose

Current view produces month-to-date and last-month analysis. Running history also updates durable history files such as cost-retail-history.csv and macc-benefit-ledger.csv.

3

Load and select subscriptions

Use Load from tenant, sign in with Azure CLI if prompted, then select the subscriptions to include. The export uses the signed-in identity's Cost Management and Reader permissions.

4

Run the export

Keep Run Cost Management export and Retail Prices lookup enabled for the full report. The launcher opens a run-specific PowerShell window and writes a transcript log in the run folder.

Configure settings

Local tab

Local output root is where timestamped run folders are created. History root is the durable folder used across runs for history and ledger files.

Agreement tab

Enter agreement ID, customer name, agreement dates, commitment amount, currency, and pacing thresholds. These values drive MACC burn-down and pacing outputs.

Cloud tabs

Azure Blob and ADLS Gen2 upload the local run folder after export. SharePoint mode captures the target URL for Power BI, but files must be copied or synced to that location.

Settings tab

Save settings to JSON to reuse tenant, subscription selections, output roots, cloud destinations, and agreement metadata.

If a run fails before data files are written, Power BI may load empty header-only files. Rerun the export successfully, then point Power BI to the completed run folder.

Use the Power BI report

Open powerbi\Cost-Management.pbip. In Power BI Desktop, update parameters from the run folder's powerbi-storage-settings.json, then refresh.

Monthly review workflow

1. Run history mode

Run after monthly billing data is stable. Use the same history root across runs.

2. Refresh Power BI

Apply the generated parameter values and refresh the PBIP.

3. Review commitment

Check utilization, remaining commitment, expected burn, and required monthly run rate.

4. Validate evidence

Review price audit and exceptions before sharing customer-facing savings claims.

5. Reconcile billing

Fill invoice totals in billing-reconciliation.csv and document variance explanations.

6. Assign ownership

Maintain ownership-mapping.csv for business unit, application, owner, and cost center accountability.
