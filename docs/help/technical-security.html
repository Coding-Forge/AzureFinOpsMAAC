Security posture summary

The solution uses the signed-in Azure CLI identity. It does not require storage account keys, SAS tokens, or embedded secrets. Access is governed by Azure RBAC, Cost Management permissions, and any storage/data-plane permissions needed for the chosen output destination.
AreaSecurity posture
AuthenticationAzure CLI device-code or existing Azure CLI session. Tokens are managed by Azure CLI, not by the scripts.
AuthorizationCurrent user must have permission to list subscriptions, query Cost Management, list resource groups, and upload to selected storage if cloud output is used.
SecretsNo storage keys, client secrets, or SAS tokens are stored by the launcher. Settings files contain paths, selected options, agreement metadata, and subscription IDs.
Data sensitivityExports contain subscription IDs/names, service names, resource groups, regions, usage quantities, costs, retail prices, and tags when resource group export is enabled.
Data locationFiles are written locally first, then optionally uploaded to Azure Blob or ADLS Gen2. SharePoint mode requires manual copy/sync.
AuditabilityRun transcripts, generated query JSON, manifests, and CSV outputs support review and troubleshooting.

Scripts and responsibilities

ScriptWhat it doesExternal callsOutputs
Start-FinOpsDataPull.ps1 Windows Forms launcher. Collects tenant, subscriptions, output destination, agreement metadata, and run options. Generates a timestamped run-finops-data-pull.ps1. az account show, az login, az account list, optional winget install Microsoft.AzureCLI, Blob/ADLS upload commands after export. Run script, powerbi-storage-settings.json, transcript log, and uploaded files when cloud storage is selected.
Get-CostAnalysis.ps1 Queries Azure Cost Management for MTD and last-month actual costs, normalizes region names, joins to Azure Retail Prices, and exports enriched CSV/JSON data. az rest to management.azure.com/.../Microsoft.CostManagement/query, az account list-locations, Invoke-RestMethod to https://prices.azure.com/api/retail/prices. Cost query JSON, raw cost JSON, cost CSVs, retail join CSVs, enriched retail comparison CSVs, summary CSVs.
Get-AzureResourceGroupsByLocation.ps1 Lists resource groups and location metadata for selected subscriptions. az account list-locations, az group list, az account set. Resource group detail CSV/JSON and location summary CSV.
New-FinOpsAuditArtifacts.ps1 Reads enriched cost and retail CSVs and generates MACC agreement, ledger, exception, reconciliation, manifest, and ownership files. No network calls. Reads/writes local CSV/JSON files. agreement-config.csv, macc-agreement-status.csv, macc-benefit-ledger.csv, agreement-price-audit.csv, retail-match-exceptions.csv, and related audit files.
build-release.ps1 Packages a release folder and optional zip. Local file copy and optional git metadata lookup. No cloud calls. Release folder, zip, SHA256 file, release manifest.

Data created and control points

DataContainsControl recommendation
Cost export CSV/JSONCosts, usage quantities, service names, regions, resource groups, subscription identifiers.Store in approved customer-controlled location. Restrict to FinOps, finance, and authorized engineering users.
Retail price artifactsRetail price, SKU, meter, product, region, and match status.Not secret, but should be kept with cost data for audit consistency.
Agreement artifactsAgreement dates, commitment amount, pacing status, estimated eligible spend.Treat as business-sensitive; limit to agreement stakeholders.

Engineering review checklist

  • Confirm Azure CLI authentication is acceptable for the customer environment.
  • Confirm Cost Management permissions are scoped appropriately.
  • Confirm output and history folders are in an approved storage location.
  • Confirm cloud upload destinations use identity-based access, not keys embedded in scripts.
  • Confirm release packages exclude internal-docs, generated exports, logs, local Power BI cache, prior zips, and temp files.
  • Confirm users understand that estimated savings are directional and require exception review before customer-facing claims.
  • Confirm billing reconciliation is completed before using the report as a financial source of record.
